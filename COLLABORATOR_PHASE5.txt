## PARTS YOU CAN BUILD FULLY (no dependency on Phase 4)

These are 100% independent — build them completely:

1. MusicPlayer.tsx UI layout — album art, controls, seek bar, volume
2. TrackList.tsx UI layout — scrollable list, active track highlight
3. Like button — saves to Firestore (firestore.ts already has the db instance)
4. WhatsApp share button — just a link, no API needed:
   window.open(`https://wa.me/?text=Check out this song on MoodiFy: ${spotifyUrl}`)
5. Web Share API button:
   navigator.share({ title: trackName, url: spotifyUrl })
6. Artist page UI — image, name, genres, follower count, top tracks list
7. Album grid UI — album art, name, release year
8. Mood Room UI — room code input, create/join buttons, synced playlist view
9. "Open in Spotify" button — just an anchor tag with spotifyUrl
10. Mood override dropdown — manual mood selector
11. All theme-aware styling using useTheme() from context/ThemeContext.tsx

## DESIGN SYSTEM — Follow as per ther provided UI templets (Mostly similar)

Dark mode (default):
  Background:   #0a0a0a
  Cards:        #111111
  Borders:      #2a2a2a
  Muted text:   #aaa
  Accent:       #FF6B35 (orange)

Light mode:
  Background:   gradient #FFE8D6 → #FFF5F0
  Cards:        white
  Borders:      #FFDDD2
  Muted text:   #7A6055
  Accent:       #FF6B35 (orange)

Fonts:
  Brand name "MoodiFy" only:   font-pacifico
  Everything else:             font-comfortaa

Theme hook:
  import { useTheme } from "@/context/ThemeContext"
  const { theme } = useTheme()
  const isDark = theme === "dark"
